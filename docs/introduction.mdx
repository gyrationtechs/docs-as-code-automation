Acme Mail is a transactional email API. The Node.js SDK wraps the REST API so you can send email and manage webhooks in a few lines of code.

<Note>
Acme Mail is a fictional product. It exists to demo an AI-assisted docs pipeline.
</Note>

## What You Can Do

- [Send an email](/guides/send-email) to one recipient or up to 50.
- [Receive delivery events](/guides/webhooks) with webhooks.
- Look up the status of a sent message with [`messages.get()`](/sdk/messages#get).
