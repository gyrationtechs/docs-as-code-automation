Use `client.messages.send()` to send an email. The call returns as soon as Acme Mail queues the message.

**Prerequisites:** the SDK is installed and `ACME_MAIL_API_KEY` is set. See the [quickstart](/quickstart).

## Send a Basic Email

<CodeGroup>

```js JavaScript
import { AcmeMail } from '@acme/mail';

const client = new AcmeMail(process.env.ACME_MAIL_API_KEY);

const { messageId } = await client.messages.send({
  from: 'you@example.com',
  to: 'friend@example.com',
  subject: 'Your receipt',
  html: '<p>Thanks for your order.</p>',
  text: 'Thanks for your order.',
});
```

```bash cURL
curl -X POST https://api.acmemail.dev/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"from":"you@example.com","to":["friend@example.com"],"subject":"Your receipt","text":"Thanks for your order."}'
```

</CodeGroup>

Provide `html`, `text`, or both. The SDK throws an error if both are missing.

## Send to Multiple Recipients

Pass an array to `to`. You can send to up to 50 recipients in one call.

```js JavaScript
await client.messages.send({
  from: 'you@example.com',
  to: ['ana@example.com', 'ben@example.com'],
  subject: 'Team update',
  text: 'The release shipped.',
});
```

## Tag Messages

Add up to 5 `tags` to filter delivery events later.

```js JavaScript
await client.messages.send({
  from: 'you@example.com',
  to: 'friend@example.com',
  subject: 'Password reset',
  text: 'Use this link to reset your password.',
  tags: ['auth', 'password-reset'],
});
```

## Schedule an Email

Pass `scheduledAt` to send a message later. It accepts an ISO 8601 timestamp or a `Date` between 1 minute and 72 hours from now.

**Prerequisites:** the SDK is installed and `ACME_MAIL_API_KEY` is set. See the [quickstart](/quickstart).

```js JavaScript
import { AcmeMail } from '@acme/mail';

const client = new AcmeMail(process.env.ACME_MAIL_API_KEY);

const inOneHour = new Date(Date.now() + 60 * 60 * 1000);

const { messageId, status } = await client.messages.send({
  from: 'you@example.com',
  to: 'friend@example.com',
  subject: 'Your trial ends soon',
  text: 'Your trial ends tomorrow.',
  scheduledAt: inOneHour,
});
```

A successful call returns a `messageId` and a `status` of `scheduled`. Keep the `messageId` so you can cancel the message later.

<Note>
The SDK throws an error before it calls the API if `scheduledAt` is not a valid date or is outside the 1 minute to 72 hour window.
</Note>

## Cancel a Scheduled Email

Call `client.messages.cancel()` with the `messageId` that `send()` returned for a scheduled message.

**Prerequisites:** a message sent with `scheduledAt` whose send time has not passed.

```js JavaScript
import { AcmeMail, AcmeMailError } from '@acme/mail';

const client = new AcmeMail(process.env.ACME_MAIL_API_KEY);

try {
  const { status } = await client.messages.cancel('YOUR_MESSAGE_ID');
  console.log(status);
} catch (error) {
  if (error instanceof AcmeMailError && error.code === 'already_sent') {
    console.error('The message was already sent.');
  }
}
```

A successful call returns the `messageId` and a `status` of `canceled`. If the send time has passed, the call throws an `AcmeMailError` with status `409` and code `already_sent`.
{/* VERIFY: the API returns status 409 with code `already_sent` when you cancel a message whose send time has passed */}

## Handle Errors

Failed requests throw an `AcmeMailError` with the HTTP `status` and an API error `code`.

```js JavaScript
import { AcmeMail, AcmeMailError } from '@acme/mail';

try {
  await client.messages.send({ from: 'you@example.com', to: 'friend@example.com', subject: 'Hi', text: 'Hi' });
} catch (error) {
  if (error instanceof AcmeMailError) {
    console.error(error.status, error.code, error.message);
  }
}
```
